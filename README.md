## Introduction

Integrating artificial intelligence into daily security operations, ethical hacking workflows, and vulnerability research enhances operational speed, telemetry analysis, and threat discovery. Hosted on [Learn SecByte](https://learn.secbyte.org/), this foundational and advanced AI-assisted security collection provides practical, hands-on training to build custom AI security assistants, master command-line copilots, and optimize security operations.

From setting up Claude Code as a terminal-native security assistant and constructing custom AI hacking assistants to mastering prompt engineering for SecOps, accelerating security research, and deploying practical AI models across offensive and defensive workflows, these exercises establish core proficiency for modern cybersecurity practitioners.

## How to Use the Labs

1. Select a challenge link from the index or category sections above.
2. Read the scenario requirements, API spec files, and target parameters on [Learn SecByte](https://learn.secbyte.org/).
3. Deploy security platforms (Claude Code CLI, Python, LangChain, Elastic Stack/Splunk, Nmap, Burp Suite) inside an isolated workstation.
4. Interact with AI security assistants, write custom API wrapper scripts, engineer operational SecOps prompts, execute pentest scenarios, and capture target flags.
